Neural Network from Scratch

Deep learning experiment

A NumPy-only MNIST classifier with dense layers, batch normalization, dropout, softmax cross-entropy, manual backpropagation, and Adam. The current repository documents 98.39% verified local test accuracy, with 98.40% macro precision, 98.38% macro recall, and 98.39% macro F1.

Stack: Python, NumPy, Streamlit
Source ↗Demo ↗

PredictX

Applied machine learning

A predictive maintenance workflow built around the AI4I 2020 dataset. It covers data checks, model comparison, classification metrics, feature importance, SHAP-compatible explanations, and a dashboard for exploring predictions.

Stack: Python, pandas, NumPy, scikit-learn, SHAP, Streamlit
Source ↗Demo ↗

Movie Recommendation Engine

Recommendation systems

A collaborative filtering recommender using SVD initialization, Alternating Least Squares, and user and item biases on MovieLens 1M. The repository includes a run-specific evaluation script for RMSE, MAE, NDCG@10, Hit Rate@10, and catalog coverage; results should be regenerated rather than treated as fixed.

Stack: Python, NumPy, SciPy, Streamlit, Docker
Source ↗Demo ↗

AI Resume Classification System
