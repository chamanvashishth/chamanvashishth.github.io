# 💻 Chaman Vashishth — Portfolio

A personal portfolio website built with a **Windows PowerShell-inspired interface** and a jet-black visual theme. 🖥️

## 🌐 Live Website

**Visit:** [chamanvashishth.github.io](https://chamanvashishth.github.io/)

## 📌 Overview

The portfolio presents my work, projects, technical stack, open-source contributions, achievements, certifications, and professional links through a Windows PowerShell-style interface.

### 📂 Sections

- 👤 `whoami` — introduction
- 🔗 `links.txt` — GitHub, LinkedIn, X, Discord, and email
- 🚀 `shipped\` — featured projects
- 🤝 `contributing\` — open-source contributions
- 💼 `experience.txt` — experience and internships
- 🧠 `stack.txt` — technical stack
- 🏆 `achievements.txt` — achievements and selections
- 📜 `certifications.txt` — certifications
- ℹ️ `about.txt` — background and interests
- 📁 `projects.txt` — project details

## 🚀 Featured Projects

- 🧠 **Neural Network From Scratch** — NumPy-based implementation with manual backpropagation.
- 🎬 **Movie Recommendation Engine** — collaborative filtering using ALS and SVD.
